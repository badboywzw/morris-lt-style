# 写作手册

## 把观点变成机制

在起稿前选出与问题有关的变量。以下表格是内部思考工具，用户只要短文时无需输出表格。

| 观察角度 | 应回答的问题 | 常见失误 |
|---|---|---|
| 位置 | 资源、渠道、技能、环境中，哪个变量限制结果？ | 把处境归为“认知不够” |
| 激励 | 做与不做分别有什么收益和成本？ | 只讨论一个人应该怎样 |
| 积累 | 重复后留下什么？怎样知道方向有效？ | 把坚持时间当作有效证据 |
| 选择权 | 有什么替代方案？退出需要什么条件？ | 用“勇敢辞职”替代方案分析 |
| 情绪与事实 | 哪些已发生，哪些只是推测？ | 把所有负面情绪都说成内耗 |

## 常用体裁

**一句话**：保留一个清楚的判断或区分，避免三层抽象名词连用。

**一段短文**：具体问题 → 关键区分 → 机制 → 小范围可验证的行动。通常 100–300 字，不必机械满足字数。

**清单**：按同一维度选择项目，例如“能改变的位置”或“反馈是否有效”。不要把态度、措施与结果混在同一层。

**改写或评审**：忠实保留原意，先修复因果、事实和限定条件，再调整语气。用户要求评审时，指出具体跳步，并给出替代版本。

## 原创示例

以下为本项目编写的演示，不是 Morris 原帖。

### 一句话：积累

重复能不能留下积累，要看下一次行动是否用上了上一次的反馈。

### 短文：努力很久却没有积累

为什么忙了很久，仍然觉得自己停在原地？可以先看每次投入留下了什么。处理完一件事，只消除了当下的任务；把处理方法整理成可复用的流程，才可能降低下一次的成本。如果方向始终缺少外部反馈，熟练也可能只是更快地重复无效动作。与其单看投入了多少小时，不如每周检查一次：留下了哪些作品、哪些方法得到验证、哪些判断需要修正。积累需要时间，也需要让时间投入的结果被看见、被检验。

### 清单：改善工作中的位置

先识别当前岗位最稀缺的能力，再检查自己是否能接触真实反馈，是否有可展示的成果，是否存在转向其他任务的通道。每次选择一个能验证的变量，避免同时更换所有条件后仍说不清原因。

## 必要的限定

“选择”“位置”“秩序”等词需要落实到当前议题中的具体变量。面对制度、市场或复杂社会现象，保留多个机制同时作用的可能；不从少数例子推导全体结论。

报告覆盖 2026-10-11 至 2026-10-24 的 183 条样本，部分长帖截断，因此长度统计可能偏低。互动、价格、粉丝数与发帖时间是历史快照；不能据此保证内容效果或给出现行价格。
