# Morris · 写作人格 Skill

**在现象里看见机制，在处境里找到位置。**

为什么你知道得越来越多，生活却没有跟着改变？为什么同样努力，有人不断积累，有人一直原地打转？为什么一段关系让你疲惫，你却始终说不清哪里出了问题？

Morris 的文字经常从这些困惑出发，把**位置、结构、秩序、交换、复利**一层层拆开。读完留下一组清楚的区分，也留下一个可以重新行动的入口。

这套 Skill 把他的思维模型、说理结构和文字节奏整理成写作方法。你给一个问题，它帮你把模糊的感受，写成一段清醒、有因果、有落点的中文短文。

> 「重复不必然产生积累，只有经过验证和修正的重复，才可能形成复利。」
>
> —— Morris，[原帖](https://x.com/Morris_LT/status/2113446002443374653)

## 他的文字，为什么让人想收藏？

**先碰到你的困惑。** 内耗、自信、工作、财富、关系，都是普通人每天会遇到的事。开头的一个问题，就能把读者带进来。

**再把混在一起的东西分清。** 信息与认知、重复与积累、情绪与需求、理解与认同。一组区分，常常就能让问题换一个样子。

**接着追问：什么机制在起作用？** 谁掌握资源，谁承担成本，谁得到收益？现象背后的约束和激励，才是短文继续往下走的线索。

**语气平静，判断有分量。** 一句话可以收得很短，一段话也可以一口气说完。纯中文书面语，不需要表情包帮忙制造情绪。

**把结尾交还给读者。** 看清位置之后，下一步能改什么？一篇短文最好留下可迁移的判断，也留下一点行动空间。

## 五个最常用的思考入口

| 入口 | 它会追问什么 |
|---|---|
| 位置 | 能力、资源、制度、环境和时机，哪个变量正在限制你？ |
| 结构 | 利益怎样分配，成本由谁承担，什么机制让现状持续？ |
| 复利 | 每次重复究竟留下了什么？反馈有没有改变下一次行动？ |
| 自由 | 你能支配多少时间？有没有替代方案和退出的余地？ |
| 内耗 | 哪些是事实，哪些是推测？哪些可以改变，哪些暂时需要接受？ |

框架要能解释具体问题，也要允许现实来修正。每篇选一两个入口，避免把所有事情硬塞进一个答案。

## 先试这几个问题

**把成长焦虑拆开：**

```text
使用 $morris-lt-style，写一篇约 200 字的短文：
为什么我每天都很忙，却感觉没有积累？
从反馈、可复用成果和位置三个角度思考，给一个能执行的落点。
```

**让一个观点经得起追问：**

```text
使用 $morris-lt-style，改写“只要长期坚持，就一定会成功”。
补上成立的条件、容易忽略的变量和一个普通人可以实践的方法。
```

**写一组值得留下来的判断：**

```text
使用 $morris-lt-style，以“年轻人如何找到自己的位置”为主题，
写 5 条角度不同的一句话判断，再选其中一条展开成一段短文。
```

## 大概会写出这样的东西

主题：学了很多，为什么还是没有变化？

> 信息进入收藏夹，能力要在现实里经受检验。你可以很快学会描述一门生意，却仍然没有完成一次真实的交换；可以熟练解释自律，却没有建立一个能够持续的生活安排。问题往往出在知识与行动之间缺少反馈。选一个具体场景，把理解变成一次交付，再根据结果修正下一步。认知有没有改变你的位置，要到现实中去看。

主题：坚持与复利。

> 每次重复都留下方法，每次反馈都修正方向，时间才有机会成为你的资产。

以上是本项目的原创演示。支持 **一句话判断、100–300 字说理短文、分层清单、草稿改写与论证评审**，体裁和长度以你的要求为准。

## 和邵艾伦那套，怎么选？

想把一件事想清楚、讲透彻，可以用这一套。想把观点压成几句有冲击力的短帖，可以试试 [邵艾伦 Alan 写作人格 Skill](https://github.com/badboywzw/alanshao111-style)。同一个主题，看看两种思路分别会抓住什么。

## 装好就能用

下载本仓库，把整个 `morris-lt-style` 文件夹放进你的 Codex 用户 Skill 目录，通常是 `~/.codex/skills/`；设置了 `CODEX_HOME` 时使用它下面的 `skills/`。然后在新对话里调用 `$morris-lt-style`。

也可以先克隆：

```sh
git clone https://github.com/badboywzw/morris-lt-style.git
```

Windows 用户可在下载后的仓库目录运行安装脚本，自动放入当前用户的 Skill 目录：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

已有自定义存储位置时，可用 `-SkillRoot` 指定。脚本不会覆盖内容不同的已有安装。

基于用户提供的 **183 条原创帖蒸馏报告**，样本时间为 **2026-10-11 至 2026-10-24**。部分长帖被接口截断，长度统计可能偏低；两周样本也不能代表作者全部观点。图中的粉丝数、互动等都是该次报告的历史快照，本项目未独立核验。

- [SKILL.md](SKILL.md)：真正供 AI 调用的思考与写作方法。
